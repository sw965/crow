# 全結合限定の探索報告: FC-Bitplane MLP

## 1. 結論

今回追加された「全結合ニューラルネットワーク以外を使わない」という制約では、
従来の `model/` にある局所受容野モデルは対象外になる。TM、AND節、局所受容野、畳み込みも
候補から除外した。

条件を満たした実用候補は、次の **FC-Bitplane MLP** である。

```text
二値入力 (784 bit)
  -> 全結合二値しきい値層 (8192 units、W in {-1,+1}、整数bias)
  -> 全結合整数読み出し (10 classes、平均化パーセプトロンで学習)
  -> 推論前に整数重みを符号bit + 絶対値bit planesへ厳密変換
```

検証用10,000件を学習集合から分離し、その精度でエポックを選んだ3シードの最終test精度は
次のとおりだった。

| データセット | seed 1 | seed 2 | seed 3 | 平均 ± 標準偏差 | crow BEP |
|---|---:|---:|---:|---:|---:|
| MNIST | 96.16 | 96.20 | 96.00 | **96.12 ± 0.09** | 92.13 ± 0.48 |
| Fashion-MNIST | 86.19 | 86.39 | 86.45 | **86.34 ± 0.11** | 83.78 ± 0.03 |

BEP論文のFashion-MNIST報告帯は約85〜87%なので、本手法はその範囲内で、crow実装を
平均+2.56pt上回る。MNISTではcrow実装を平均+3.99pt上回る。

## 2. 6条件への対応

| 条件 | 判定 | 根拠 |
|---|---|---|
| ビット演算・整数が中核 | 適合 | 隠れ層はXNOR相当のXOR+popcount、出力学習は整数±1更新、推論はAND+popcount+shift+整数加算 |
| ニューラルネットワーク | 適合 | 符号活性を持つ全結合ニューロン層と全結合線形読み出しからなるMLP |
| 全結合以外を使わない | 適合 | 各隠れニューロンは784入力すべて、各出力は8192活性すべてへ結線。局所受容野・畳み込み・TMなし |
| 3値を使わない | 適合 | 隠れ可視重みと活性は常に{-1,+1}。読み出しは3値テンソルではなく、整数を二値bit planesで格納 |
| 万能近似 | 適合（モデル族） | §5の構成。固定小数点の入出力精度、幅、整数型幅を要求精度に応じて増やす |
| BEP同等以上の精度 | 適合 | §1の検証分離・3シード結果 |

読み出しの整数0は「3値重みの第3状態」ではない。推論表現では絶対値bitがすべて0の
ビット列であり、各保存要素は0/1の二値である。中核に `{-1,0,+1}` の1要素3状態を持つ
テンソルや、TMのリテラル包含/除外状態は存在しない。

## 3. 演算

### 3.1 全結合二値しきい値層

入力 `x` とニューロン `j` の二値重み `W_j` に対し、次を計算する。

```text
mismatch_j = popcount(x XOR W_j)
z_j = 784 - 2 * mismatch_j + bias_j
a_j = (z_j >= 0)
```

実験で最良だった分類用インスタンスは、ランダムな二値重みと `bias_j = 0` を使う。
重み生成も整数PRNGだけで行う。隠れ層を固定するランダム特徴MLPなので、学習対象は読み出しである。
全層を学習しなければならない、という条件は今回の6条件には含まれていない。

### 3.2 マージン付き平均化パーセプトロン

出力層は、正解クラスの整数logitが最良の誤クラスより `margin` 以上大きくないとき、
発火中の特徴について正解クラスを+1、誤クラスを-1する。平均重みは次の整数除算で得る。

```text
averageWeight = currentWeight - accumulator / updateCount
```

浮動小数点の学習率、勾配、乗算はない。平均化を外した対照はFashion-MNIST 84.53%で、
平均化ありの86.19%より1.66pt低かった。

### 3.3 ビットプレーン推論

学習済み整数重み `q` を、負号bitと `abs(q)` の各bitへ分解する。bit位置 `b` ごとに、
発火bitsetとのANDをpopcountし、負号bitとのANDをもう一度popcountする。

```text
count_b = popcount(active AND magnitudePlane_b)
negative_b = popcount(active AND magnitudePlane_b AND signPlane)
logit += (count_b - 2 * negative_b) << b
```

これは近似量子化ではなく、元の整数logitとビット単位で厳密に一致する。
今回の学習済みモデルは絶対値8bitで収まり、符号を含めて9bit/重みだった。
従来の `int32` から読み出し重みの保存量を71.9%削減する。

Fashion-MNIST、幅8192、test 10,000件を5回推論した測定では、読み出し部分が
329.5msから199.0msへ **1.66倍高速化**した。隠れ活性の生成は10,000件で約244msだったため、
ビットプレーン読み出しを含む全推論は約28us/件（12ワーカー、同一CPU）である。

## 4. 実験

### 4.1 再現コマンド

```sh
# Fashion-MNIST
go run ./model/mlp/binary/nnlab/ablation \
  -dataset fashion -type dense -hidden 8192 -epochs 15 -avg \
  -validation 10000 -benchruns 5 -seed 1 -threads 12

# MNIST
go run ./model/mlp/binary/nnlab/ablation \
  -dataset mnist -type dense -hidden 8192 -epochs 15 -avg \
  -validation 10000 -benchruns 1 -seed 1 -threads 12
```

seedを1、2、3に替えて3回実行した。validationで選ばれたエポックは、MNISTが
15 / 15 / 14、Fashion-MNISTが8 / 5 / 7だった。testは選択に使っていない。

### 4.2 幅の比較（Fashion-MNIST、seed 1）

| 幅 | test精度 | 判定 |
|---:|---:|---|
| 4,096 | 85.63% | crow BEPを超える最小寄りの構成 |
| 8,192 | 86.19% | 速度・精度の主推奨 |
| 16,384 | 86.79% | 精度優先 |
| 32,768 | 打ち切り | 1エポック38.7秒まで悪化し、高速性に不利 |

32,768は精度を見る前に打ち切った。幅を増やせば常に実用上良い、とは判断しない。

### 4.3 反証された候補

全結合という条件内で、学習画像全体を二値テンプレート重みにする `densematch` も試した。
局所受容野は使わず、各ニューロンは全784画素を見る。幅8192、10エポック、seed 1の結果は
次のとおりで、採用候補より明確に悪かった。

| 発火に必要な一致率 | test精度 |
|---:|---:|
| 75% | 82.61% |
| 80% | 83.21% |
| 85% | 83.11% |

画像の背景一致に強く影響され、ランダム全結合射影の多様性を下回ったと考えられる。
既存の `REPORT.md` §2.1 にあるランダム整数バイアスも、MNIST幅8192で
95.93%から95.51%へ下がっている。したがって、分類用の実測最良はゼロバイアスの
ランダム全結合二値層だった。ただし整数バイアスを持てること自体は万能近似性に必要なので、
モデル族からは削除しない。

### 4.4 学習速度

幅8192では、50,000件の隠れ活性生成が約1.2秒、読み出し1エポックが約1.9〜2.0秒だった。
15エポックの中核学習は約30秒である。同じ環境で既存BEP 784->512->1024を1エポック
動かすと4.9秒だった。BEP報告値は50エポックの結果なので、本候補は固定隠れ層と活性キャッシュにより
学習を短くできる。ただしBEPの50エポック総時間を直接測った比較ではない。

## 5. 万能近似性

万能近似性は1個の固定サイズモデルではなく、精度に応じて幅と入出力bit数を増やせるモデル族の
性質として扱う。`../UNIVERSAL_APPROXIMATION.md` §4.2の構成を、この全結合モデル族がそのまま含む。

入力 `x, p in {-1,+1}^d` に対し、入力パターン `p` の検出ニューロンを置く。

```text
h_p(x) = sign(p^T x - (d - 1))
```

これは全入力へ二値重み `p` で結線され、整数バイアス `-(d-1)` を持つ全結合ニューロンである。
全入力パターンに1個ずつ置くと、入力を完全に識別できる。出力bit `k` の目標を
`y[p,k] in {-1,+1}` とし、検出ニューロン `p` から出力 `k` への二値重みを `y[p,k]`、
整数バイアスを `sum_p y[p,k]` にすると、入力 `p` の出力活性前値は厳密に `2*y[p,k]` になる。

`main_test.go` の `TestFullyConnectedBinaryNetworkRepresentsTruthTable` は、5bit全入力と
ランダムな7bit出力真理値表について、この構成を全件検証する。重みは両層とも二値、
バイアスと活性前値は整数で、全結合以外の構造はない。

連続入力では、要求誤差に応じて細かくできる固定小数点・二値符号でコンパクト集合を有限セル化し、
出力も可変bit数の固定小数点にする。一様連続性によるセル内誤差と出力量子化誤差をそれぞれ
`epsilon/2` 未満にすれば、全誤差を `epsilon` 未満にできる。したがって、可変の入力精度、幅、
出力精度、整数型幅を持つFC-Bitplane MLP族は、コンパクト集合上の連続関数を任意精度で近似できる。

これは表現能力の存在証明であり、平均化パーセプトロンが任意の対象関数の構成へ必ず収束する、
という主張ではない。

## 6. 実装変更

`ablation/` に次を追加した。

- 学習集合からのvalidation分離と、validationによる最良エポック選択
- 整数logitを厳密再現するビットプレーン読み出しと速度測定
- 全結合データテンプレート候補 `densematch`（反証実験用）
- ビットプレーンと整数logitの全件一致テスト
- 全結合二値ネットによる任意真理値表の構成テスト

ライブラリ本体 `binary` の公開APIや既存テストは変更していない。

## 7. 限界

- Fashion-MNISTでBEP論文報告帯には入ったが、局所受容野モデルの87.96%には届かない。
  そのモデルは今回の全結合限定条件に違反するので比較対象には採用しない。
- 隠れ層は固定ランダムで、学習するのは読み出しだけである。これは6条件には適合するが、
  「全層を教師ありで学習する」という追加条件がある場合は未達になる。
- 速度はWindows 11、12論理コアCPU上のGo実装による壁時計で、ハードウェアXNOR命令の実測ではない。
- MNIST/Fashion-MNIST以外、回帰、多出力固定小数点の精度は未検証。
