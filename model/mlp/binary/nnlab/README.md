# nnlab — 純粋な二値NNで TM 並みの精度を出すための実験

> **全結合限定条件について:** このREADMEの従来提案 `model/` は局所受容野を使うため、
> 「全結合ニューラルネットワーク以外を使わない」という追加条件には適合しない。
> その条件での新しい候補、検証分離した3シード精度、ビットプレーン推論、万能近似構成は
> `FULLY_CONNECTED_REPORT.md` を参照。

「第1層から出力層まで純粋なニューラルネットワーク構造は崩さず、3値は導入せず、
BEPの高速性の核は崩さず、実用的な精度が出て、万能近似定理を満たすモデル」
という依頼(2026-08-14)に対する探索の成果物一式。

到達した構成は **局所受容野を持つ二値ニューロン層(競合学習)+ 整数重みの出力層
(マージン付き平均化パーセプトロン)**。全経路が整数・ビット演算のみ。

| データセット | 本手法 | TM(`../tsetlinlab/`) | crow BEP(`../REPORT.md`) |
|---|---:|---:|---:|
| MNIST | **97.97 ± 0.07%**(3シード) | 97.24 ± 0.12 | 92.13 ± 0.48 |
| Fashion-MNIST | **87.96%**(1シード) | 87.44 ± 0.11 | 83.78 ± 0.03 |

探索の過程で出た、当初の見立てを覆す結果が2つある。詳細は `REPORT.md`。

- **BEPの弱点は表現力ではなく学習則の側にある。**
  BEPの学習済み特徴は、同じ幅のランダム特徴より弱い(REPORT.md §2.1)
- **誤差駆動のHebbian則(BEPと同じ構造)は第1層の特徴を破壊する。**
  更新を弱めるほど精度が上がるという単調な関係だった。
  勝者のみを更新する競合学習に替えると、逆に精度が上がる(REPORT.md §4)

## ファイル構成

| パス | 内容 |
|---|---|
| `REPORT.md` | 調査・実験の完全な報告。結論、切り分け実験、提案モデル、学習則の知見、万能近似、限界 |
| `LOGS.md` | 全実験の生ログ |
| `model/` | **提案モデル**。局所受容野の二値ニューロン層 + 整数重み出力層。全層を学習する |
| `ablation/` | 特徴の種類(dense / densebias / and / conv)× 読み出し(proto / linear)の対照実験 |
| `bepreadout/` | 既存BEPの読み出しだけを整数線形に差し替える診断実験 |

`model/` と `ablation/` には自動テストがある(参照実装との一致、受容野の局所性、
競合学習が勝者を特化させる事、平均化重みの一致、合成タスクでの学習性など)。

## 実行方法

初回実行時に `~/.crow_dataset` へデータセットが自動ダウンロードされる。

```sh
# 提案モデル(MNIST 97.9%前後)
go run ./model -hidden 16384 -patch 9 -randinit -matchpct 70 -vq 3 -freeze1 -epochs 20

# 提案モデル(Fashion-MNIST 88.0%前後)
go run ./model -dataset fashion -hidden 16384 -patch 9 -randinit -matchpct 55 -vq 3 -freeze1 -epochs 20

# 対照実験(特徴の種類を変える)
go run ./ablation -type conv -hidden 8192 -patch 9 -matchpct 85 -epochs 15 -avg
go run ./ablation -type dense -hidden 8192 -epochs 15 -avg

# BEPの読み出し差し替え診断
go run ./bepreadout -h1 0 -h2 8192 -bepepochs 15 -roepochs 15
```

`-freeze1` は「誤差駆動の第1層更新を止める」フラグで、`-vq` の競合学習はその前段で
実行される。したがって上記の設定でも**第1層は学習されている**(REPORT.md §3.3)。

第1層の誤差駆動学習(効果が無かった方)を試す場合は `-freeze1` を外す。

## 注意

- これらは実験プログラム(データ収集プログラム相当)であり、`binary` パッケージの
  ライブラリコードからは参照されない。層構造の設計規約の適用外
- **crow / omw のライブラリコードは一切変更していない**(公開APIのみ使用)
- 学習・推論の経路に浮動小数点演算はない(精度の表示のみ float)
- 精度は各実行の最良エポックのテスト精度。TM との比較条件は揃えてあるが、
  絶対値はやや楽観的(REPORT.md §7)
