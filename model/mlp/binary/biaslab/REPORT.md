# 実験報告: 整数バイアス / セルマスク / 回帰の復号方式

- 日付: 2026-08-14(バイアスとセルマスク)/ 2026-08-15(復号方式の比較を追加)
- 依頼:
  1. 各層に学習する整数バイアスを持たせたモデルを実験する。
     学習則は「バイアスと重みの両方を動かさず、どちらか片方に絞る。
     Update 時にどちらを学習するかを乱数で選ぶ。バイアスなら ±1、重みなら crow の従来どおり」
  2. セルマスクの有無も再度実験する
  3. 回帰の復号方式をいくつか比較する
     (学習パラメータを持たない方式を中心に)
- 実験環境: Windows 11 / Go 1.26.5 / 12論理コアCPU
- 実験コード: 同フォルダ `main.go`。生ログ: `LOGS.md`
- **crow / omw のライブラリコードは変更していない**

## 0. 方法論(初版から修正した点)

初版には方法論上の欠陥が3つあり、指摘を受けて修正した。**本報告の数値はすべて修正後のもの**である。

| 欠陥 | 修正 |
|---|---|
| `-seed` が学習乱数(シャッフル・ノイズ・更新選択)を固定していなかった。`randx.NewPCG` はグローバル乱数から種を取るため実行ごとに結果が変わっていた(`../PROTOTYPES.md` B-8b が crow 本体について指摘しているのと同じ問題) | 学習用の乱数をすべて `seed` から決定的に導出。同一 seed の2回実行が完全に一致する事を確認済み(`LOGS.md` §0.2) |
| テスト集合で最良エポックを選んでいた。条件によって学習曲線のばらつきが違うと、最大値を拾う上振れ量も変わるため、条件間比較も完全には公平でなかった | 学習データから検証集合を分離(既定10%)。**最良エポックと加重平均の温度は検証集合で選び、テスト集合は選択に一切使わない** |
| バイアス有りは重みの更新機会が約半分になるため、「バイアスに効果が無い」のか「重み更新が減った分の損」なのかを分離できていなかった | **更新機会を揃えた対照条件**を追加。`-bias=false -biaschoice 0.5` は「バイアス側が選ばれたニューロンは何も更新しない」となり、バイアス有りと重みの更新回数が一致する |

また、再実装が crow 本体と同一である事を、精度が近いという間接的な根拠ではなく
**1ステップずつの差分テスト**で検証した(`main_test.go`)。
`Predict` の出力、`Forward` の出力、逆伝播で溜まるデルタ、`Update` 後の `H` / `W` / `WT` が、
同じ初期値・同じ乱数列で crow の `binary.Dense` と**ビット単位で一致**する。

比較する3条件は次のとおり。

| 名前 | 設定 | 意味 |
|---|---|---|
| 従来BEP | `-bias=false -biaschoice 0` | crow と同じ計算(差分テストで一致を確認済み) |
| 対照(更新半減) | `-bias=false -biaschoice 0.5` | 重みの更新機会だけをバイアス有りと揃える。バイアスは持たない |
| バイアス有り | `-bias -biaschoice 0.5` | 依頼された学習則 |

## 1. 結論

| 変更 | 分類(MNIST/Fashion) | 回帰(合成タスク) |
|---|---|---|
| **学習する整数バイアス** | 効果なし(ばらつきの範囲) | セルマスク無しで **−0.42 改善**、有りで **+0.64 悪化**(いずれも3/3で同方向) |
| **セルマスク** | 効果なし(3シードで確認) | **決定的に効く。MAE 12.33 → 5.42(2.27倍)** |

そして初版の解釈を1つ**取り下げる**。

- 初版は「バイアスを選ぶと重みの更新機会を奪うので割に合わない」と説明したが、
  **更新機会を揃えた対照を測ったところ、重みの更新を半分に減らしてもほとんど損しない**
  (回帰マスク無しで 12.326 → 12.289、マスク有りで 5.422 → 5.557)。
  したがって「更新機会の取り合い」では説明できない。バイアスそのものの効果である

## 3. 回帰の結果

タスクは `../PROTOTYPES.md` B-8 と同じ合成回帰。入力 64x128 bit、固定の方向行列 D に対し
レベル ℓ のサンプルは各ビットが確率 `q(ℓ) = 0.35 + 0.30·ℓ/(n−1)` で D と一致する。
出力 64x64 = 4096 bit、n=101 段階の温度計プロトタイプ、学習4040件(うち10%を検証)・テスト1010件。
ハイパーパラメータは B-9 の最良設定(gsize=16 / gate=4 / lr=0.3 / margin=0.01)、30エポック。
復号は**加重平均のみ**。温度と最良エポックは検証集合で選ぶ。

### 3.1 3条件 x セルマスク(テストMAE、低いほど良い、3シード平均)

| 条件 | セルマスク無し | セルマスク有り |
|---|---:|---:|
| 従来BEP | 12.326 | **5.422** |
| 対照(更新半減) | 12.289 | 5.557 |
| バイアス有り | **11.874** | 6.193 |

シード別の値は `LOGS.md` §2 を参照。

読み取れること。

1. **セルマスクが決定的**: 12.326 → 5.422 で **2.27倍**の改善。
   3シードの範囲(11.18〜13.17 対 5.35〜5.47)が全く重ならない。
   `../PROTOTYPES.md` B-9b / B-11a の再現であり、B-11a の 5.41 ともよく一致する
2. **重みの更新を半減しても、ほとんど損しない**: 12.326 → 12.289(マスク無し)、
   5.422 → 5.557(マスク有り)。**更新機会はこのタスクの律速ではない**
3. **バイアスの効果は、対照と比べても符号が反転する**
   - セルマスク無し: 12.289 → 11.874(**−0.415 改善**)。3シードすべてで改善方向
   - セルマスク有り: 5.557 → 6.193(**+0.636 悪化**)。3シードすべてで悪化方向
   - 2 の結果により、これは更新機会の差では説明できず、バイアスそのものの効果である

### 3.2 セルマスクの有無で符号が反転する理由(仮説・未検証)

セルマスク無しの見本は温度計符号そのもので、レベルが低いほど 0 が多く、
出力層は「全体としてどれくらい点灯させるか」を大きく振る必要がある。
このとき層全体のしきい値を動かすバイアスが役に立つと考えられる。
セルマスクを掛けると全レベルの点灯率が約50%に均されるため、
その「全体の振り幅」の調整が不要になり、バイアスは利得を失って
ノイズだけが残る、という説明が考えられる。**ただし未検証の仮説である。**

## 4. 「バイアスは効かない」の正確な意味

本実験で言えるのは次のことだけである。

- **この学習則**(初期値0、±1、Update ごとにニューロン単位で重みと排他選択、
  デルタは希望活性の符号)では、分類で効果がなく、回帰では条件によって
  小さく改善したり悪化したりする

言えないこと。

- バイアスという仕組み自体が無意味である、とは言えない。
  `../nnlab/REPORT.md` §2.1 では、しきい値の**値**が精度を大きく左右することを測っている
  (局所受容野9x9で一致率85%→90%で 97.39%→96.49%、
  ランダム初期化で55%→65%で 97.02%→90.29%)
- 別の更新則(重みと同時に更新する、初期値を変える、更新幅を変える、
  層ごとに扱いを変える、選択の粒度を変える等)でも効かない、とは言えない
- 万能近似性の議論に影響はしない。バイアスは**表現能力**のために必要であり、
  それと学習で有利になるかは別問題(`../UNIVERSAL_APPROXIMATION.md` §7)

## 5. バイアスは動いているのか(診断)

「効かなかった」のか「そもそも動いていない」のかを切り分けるため、
学習後のバイアス分布と、活性前値の標準偏差を**実測**した(`reportBias` / `reportPreActivationStd`)。
初版は活性前値の標準偏差に √fanIn を当てていたが、これは
「重みと入力が独立ランダム」という仮定の値でしかないため、実測に置き換えた。

回帰、バイアス有り、10エポック、seed=1:

| 条件 | 層 | バイアス平均 | バイアス平均絶対値 | 活性前値σ(実測) | √fanIn |
|---|---|---:|---:|---:|---:|
| セルマスク有り | 0 | −8.68 | 8.84 | **11.37** | 11.31 |
| セルマスク有り | 1 | −3.47 | 5.12 | **17.85** | 16.00 |
| セルマスク無し | 0 | −10.32 | 10.41 | **11.36** | 11.31 |
| セルマスク無し | 1 | 1.97 | 4.47 | **23.79** | 16.00 |

- ほぼ全ニューロンのバイアスが非ゼロで、**動いていないわけではない**
- 平均絶対値は活性前値の実測標準偏差の 0.2〜0.9 倍。しきい値として無視できない大きさ
- 第1層では √fanIn が実測とほぼ一致するが、**第2層では 12〜49% ずれる**。
  初版が √fanIn を基準に使ったのは不適切だった

### 5.1 バイアスが負へ寄る理由(実測して初版の説明を訂正)

初版は「温度計の低レベルは0が多いので希望活性が −1 に偏る」と説明したが、
レベルは0〜100で均等に生成されるため、高レベル側の +1 と概ね釣り合うはずである。
実際に、更新対象に選ばれたサンプルの希望活性の極性を数えた。

| 条件 | 希望活性 +1 | 希望活性 −1 | −1 の割合 |
|---|---:|---:|---:|
| セルマスク有り | 22,034,138 | 24,506,662 | 52.7% |
| セルマスク無し | 22,098,071 | 24,153,976 | 52.2% |

**偏りは 5% 程度しかない。** それでも層全体が負へ寄るのは、更新則が
「バッチで集約した後に符号を取って ±1 動かす」形だからである。
1バッチあたりの偏りがわずかでも、符号を取ると ±1 に増幅され、
それが数十バッチ積み重なると系統的なドリフトになる。
結果としてバイアスは**ニューロンごとの役割分化ではなく、層一様のオフセット**を獲得する。

これは初版の説明(「温度計の低レベル」)よりも正確で、
今回の更新則の弱点(符号化による増幅で微小な偏りが蓄積する)を指している。

## 6. 回帰の復号方式の比較

復号は学習済みモデルへの後処理なので、**1回の学習で全方式を同じモデルに対して測れる**。
以下はすべて同一モデル(セルマスク有り、30エポック、seed=1)での比較である。
パラメータを持つ方式は検証集合で選び、テスト集合は選択に一切使っていない。

### 6.1 結果

| 復号方式 | テストMAE | パラメータ | 推論コスト |
|---|---:|---|---|
| 一致率をそのまま正規化 | 23.16 | なし | 距離n回 |
| 点灯数から直接(校正なし) | 20.12 | なし | **XOR1回 + popcount1回** |
| 同点平均(現行 `PredictValue`) | 17.38 | なし | 距離n回 |
| 最小を引いて正規化 (p=1) | 11.92 | なし | 距離n回 |
| 最小を引いて2乗 (p=2) | 10.79 | なし | 距離n回 |
| 加重平均 softmax | 5.44 | T | 距離n回 + exp n回 |
| **点灯数 + 線形校正** | **3.58** | **a, b の2個** | **XOR1回 + popcount1回** |

seed=2 でも点灯数+校正は 3.42 で再現した。

### 6.2 各方式の定義

ロジットは一致ビット数なので、一致率 = ロジット / 総ビット数。

```text
同点平均      : 最大ロジットのラベルだけを使い、同点なら平均(現行の PredictValue)
一致率を正規化 : w_i = logit_i / Σ logit_j            答え = Σ w_i·value_i
最小を引く     : w_i = (logit_i − min_j logit_j)^p    答え = Σ w_i·value_i / Σ w_i
softmax       : w_i = exp((logit_i − max)/T)         答え = Σ w_i·value_i / Σ w_i
点灯数        : count = popcount(y XOR prototypes[0]) 答え = a·count + b
```

### 6.3 「一致率をそのまま正規化」が効かない理由

同じ実行で測った診断値。

```text
一致率の散らばり(テスト集合): 最大 0.5557 / 最小 0.4455 / 幅 0.1102
```

最も似ているラベルでも一致率 0.556、最も遠いラベルでも 0.446 で、**差は 0.11 しかない**。
これをそのまま重みにして正規化すると、101本の重みがほぼ均等になり、
答えが値域の中央(50)へ張り付く。値が一様分布なら常に50と答えたときのMAEは25で、
実測 23.16 はほぼその状態である。

**0.5 という共通の台座に情報が埋もれている**のが原因なので、台座を外すだけで大きく改善する
(最小を引くと 23.16 → 11.92、さらに2乗で 10.79)。
一致率の幅が狭いのは、モデルの出力ビット誤り率が高いこと(`../PROTOTYPES.md` B-8e で0.45前後)の
帰結である。どの復号も「小さな差を増幅する」仕事をすることになる。

### 6.4 点灯数による復号

温度計符号はレベル i で `m_i = i·L/(n−1)` ビットを立てるので、**点灯数がそのままレベルを表す**。
セルマスク M を掛けても、温度計のレベル0が全ゼロなので `prototypes[0] = M` であり、
`y XOR prototypes[0]` でマスクを外せる(セルマスク無しの場合も `prototypes[0]` は全ゼロなので
同じ式がそのまま使える)。

```text
count = popcount(y XOR prototypes[0])
値    = a·count + b
```

**校正なしでは駄目、校正込みでは最良**という結果になった。診断が理由を示している。

| | 実測 |
|---|---|
| 校正なしの予測平均 / 真値の平均 | 49.85 / 50.00(**ずれ −0.15**) |
| 素の傾き(理論値 100/4096) | 0.02441 |
| 検証集合での最小二乗 | **a = 0.11708** / b = −189.57 |

事前に懸念していた「+1/−1 の非対称による**オフセット**」は −0.15 しかなく、無関係だった。
問題は**傾き**で、理論値の **4.8倍**ずれている。
つまり点灯数は 0〜4096 ではなく **1619〜2473 の 854ビット幅**しか振れていない。

これは `../PROTOTYPES.md` B-9a が別の方法で測った現象と一致する。

> 温度計は点灯率を 0%→100% に振ることを要求するが、モデルは 43%→62% しか振れない
> (**振れ幅が約1/5**)

1/5 = 0.2 に対し、本実験の 0.02441/0.11708 = **0.208**。独立に同じ値が出た。

### 6.5 セルマスクを外すと点灯数復号も効かない

| 復号 | セルマスク有り | セルマスク無し |
|---|---:|---:|
| 点灯数 + 校正 | **3.58** | 12.96 |
| 加重平均 softmax | 5.44 | 12.44 |
| 同点平均 | 17.38 | 19.12 |

マスク無しでは点灯数の振れ幅はむしろ広い(1421ビット 対 854ビット)のに、精度は3.6倍悪い。
**振れ幅ではなく、同じレベルのサンプル間での点灯数のばらつきが効いている**。

セルマスクは復号を邪魔する装飾ではなく、**モデルが学習しやすい目標を作るための仕掛け**である
(`../PROTOTYPES.md` B-9c: 素の温度計は「1つの行の中では64ニューロン全員が同じ答えを出す」ことを
要求するが、セルマスクは行ごとに異なるパターンを要求するので、各行が別々の入力から来る構造と整合する)。
XOR で外せるのは符号の見た目だけで、学習しやすさは外せない。

### 6.6 最良の組み合わせの手順

```text
学習時 : 温度計プロトタイプ → セルマスクを XOR → BEPで学習(学習コードは変更不要)
         Margin は 0.01 前後にする(既定の 0.5 は回帰では無効。../PROTOTYPES.md B-3)
校正   : 学習後に1回だけ、検証集合で 値 = a·count + b の最小二乗
推論   : count = popcount(y XOR prototypes[0]) → 値 = a·count + b → 値域でクリップ
```

`a`, `b` を固定小数点にすれば推論が完全に整数で閉じる。

```text
値 = (aFixed × count + bFixed) >> shift        aFixed = round(a × 2^shift)
```

得られるもの(現行比):

| | 現行(同点平均) | 点灯数 + 校正 |
|---|---|---|
| 推論の計算 | ハミング距離 101回 | **XOR1回 + popcount1回** |
| 推論に必要な保存物 | プロトタイプ101本 | **マスク1本 + 整数2個** |
| 浮動小数点 | `Values` | **なし(固定小数点化した場合)** |
| テストMAE | 17.38 | **3.58** |

参考: `../PROTOTYPES.md` B-10c の線形読み出しは 3.33 とわずかに上だが、
実数係数を L 個(4096個)持つ必要がある。

### 6.7 この節の限界

- 合成回帰タスク1つ、**セルマスク有りは seed 1・2 の2回、セルマスク無しは seed 1 のみ**
- 値と点灯数の関係が厳密に線形である保証はない。**線形当てはめの残差を調べていない**。
  曲がっているなら `../PROTOTYPES.md` B-10b の単調補正を足す余地がある
- 校正は再学習のたびに取り直す必要がある(傾きはモデルの状態に依存する)
- 実データでの確認をしていない

## 7. 制約・注意

- 分類・回帰とも全条件3シード。ただし3シードでは、
  `../PROTOTYPES.md` B-8b が警告する程度のばらつきを厳密に分離しきれない。
  「3/3で同方向」は符号検定では p≈0.125 相当であり、**示唆であって確定ではない**
- 「Update 時にランダムに選ぶ」の粒度は依頼文からは一意に決まらない。
  本実験は**ニューロン単位**と解釈した。モデル全体・層単位での解釈は未検証
- バイアスの初期値は0固定、更新幅は ±1 固定、上限は ±fanIn。これらを変えた場合は未検証
- §3.2 のセルマスクとの相互作用の説明は仮説であり、検証していない
- 回帰の復号(加重平均)は `exp` を使うため浮動小数点である。
  依頼どおり「シンプルな加重平均」を採用した結果で、**学習カーネルは整数のまま**
- 回帰は合成タスク1つのみ。実データでの確認はしていない
- 復号方式の比較(§6)の限界は §6.7 を参照
