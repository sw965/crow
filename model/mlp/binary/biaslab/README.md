# biaslab — 整数バイアス / セルマスク / 回帰の復号方式

依頼(2026-08-14〜15)の検証。3つの主題を扱う。

1. **学習する整数バイアス**を各層のニューロンに持たせる。学習則は
   「Update のたびにニューロンごとに『バイアスを動かす』か『重みを動かす』かを
   乱数で選び、両方は動かさない。バイアスなら ±1、重みなら crow の従来どおり」
2. **セルマスク**の有無を再度比較する
3. **回帰の復号方式**を比較する(学習パラメータを持たない方式を中心に)

分類は argmax。回帰は複数の復号方式を同一モデルで比較する。

## 方法論(初版から修正済み)

初版には欠陥が3つあり、指摘を受けて修正し**全面的に再測定した**(`REPORT.md` §0)。

- 学習乱数(シャッフル・ノイズ・更新選択)が seed で固定されていなかった → 固定した
- テスト集合で最良エポックを選んでいた → 検証集合を分離し、テストは選択に使わない
- バイアス有りは重み更新機会が半減する交絡があった → **更新機会を揃えた対照**を追加

また、crow 本体との**1ステップ差分テスト**を追加した。`Predict` / `Forward` /
逆伝播デルタ / `Update` 後の `H`・`W`・`WT` がビット単位で一致する。

## 回帰の復号方式の比較(2026-08-15 追加)

復号は学習済みモデルへの後処理なので、1回の学習で全方式を同じモデルに対して測れる。
セルマスク有り、30エポック、seed=1。パラメータを持つ方式は検証集合で選ぶ。

| 復号方式 | テストMAE | パラメータ | 推論コスト |
|---|---:|---|---|
| 一致率をそのまま正規化 | 23.16 | なし | 距離n回 |
| 点灯数から直接(校正なし) | 20.12 | なし | **XOR1回 + popcount1回** |
| 同点平均(現行 `PredictValue`) | 17.38 | なし | 距離n回 |
| 最小を引いて2乗 | 10.79 | なし | 距離n回 |
| 加重平均 softmax | 5.44 | T | 距離n回 + exp n回 |
| **点灯数 + 線形校正** | **3.58** | **a, b の2個** | **XOR1回 + popcount1回** |

要点。

- **一致率をそのまま重みにすると効かない。** 一致率が 0.4455〜0.5557 に密集しているため、
  正規化すると重みがほぼ均等になり、答えが値域の中央へ張り付く
- **台座(0.5)を外すだけで大きく改善する**(23.16 → 11.92 → 10.79)
- **点灯数復号は校正が必須。** ずれているのはオフセット(−0.15)ではなく**傾き**で、
  理論値の4.8倍。点灯数は 0〜4096 ではなく 854ビット幅しか振れていない。
  これは `../PROTOTYPES.md` B-9a の「振れ幅が約1/5」と一致する(実測 0.208)
- **セルマスクを外すと点灯数復号も効かない**(3.58 → 12.96)。
  セルマスクは復号の邪魔ではなく、モデルが学習しやすい目標を作る仕掛けである
- 最良の組み合わせ(セルマスク + 点灯数 + 線形校正)は、現行比で
  **計算量101分の1・保存量100分の1・MAE 4.9倍改善**。`a`,`b` を固定小数点にすれば
  推論が完全に整数で閉じる。手順は `REPORT.md` §6.6

## バイアスとセルマスクの結果(詳細は `REPORT.md`)

3条件を比較する。従来BEP(`-biaschoice 0`)、対照(`-bias=false -biaschoice 0.5`、
重みの更新機会だけを揃える)、バイアス有り(`-bias -biaschoice 0.5`)。

| 変更 | 分類(MNIST/Fashion) | 回帰(合成タスク) |
|---|---|---|
| 学習する整数バイアス | 効果なし(全条件 ±0.3pt 以内) | 対照比でマスク無し **−0.42 改善**、マスク有り **+0.64 悪化**(いずれも3/3で同方向) |
| セルマスク | 効果なし(3シードで確認) | **MAE 12.33 → 5.42(2.27倍)** |

**初版の解釈を1つ取り下げた。** 「バイアスを選ぶと重み更新の機会を奪うので割に合わない」
と書いたが、更新機会を揃えた対照を測ると、**重み更新を半分に減らしてもほとんど損しない**
(12.326 → 12.289)。更新機会の取り合いでは説明できない。

その他の実測:

- バイアスは実際に動いている。平均絶対値は活性前値の**実測**標準偏差の 0.2〜0.9 倍
- 希望活性の極性の偏りは 5% 程度しかないが、バッチ集約後に符号を取って ±1 動かす
  更新則がそれを増幅し、層一様の負方向ドリフトになる

## 実行方法

```sh
# 回帰: 3条件(従来BEP / 対照 / バイアス有り)
go run . -task regress -bias=false -biaschoice 0   -cellmask -epochs 30 -lr 0.3 -margin 0.01 -gsize 16 -gate 4
go run . -task regress -bias=false -biaschoice 0.5 -cellmask -epochs 30 -lr 0.3 -margin 0.01 -gsize 16 -gate 4
go run . -task regress -bias       -biaschoice 0.5 -cellmask -epochs 30 -lr 0.3 -margin 0.01 -gsize 16 -gate 4

# 分類
go run . -task classify -dataset mnist -bias -biaschoice 0.5 -cellmask=false -epochs 20 -seed 1
```

`-biaschoice 0` かつ `-bias=false` にすると crow の BEP と完全に同じ計算になる
(乱数消費も含めて一致することを差分テストで確認済み)。

## 注意

- **crow / omw のライブラリコードは変更していない**
- 実験プログラム(データ収集プログラム相当)であり、`binary` パッケージの
  ライブラリコードからは参照されない
- 学習カーネルは整数・ビット演算のみ。復号のうち softmax は `exp` を使う(評価側の処理)。
  点灯数復号は `a`,`b` を固定小数点にすれば完全に整数で閉じる
- 「Update 時にランダムに選ぶ」の粒度は**ニューロン単位**と解釈した。
  モデル全体・層単位の解釈は未検証
- 3シードでは「3/3で同方向」は符号検定で p≈0.125 相当。示唆であって確定ではない
- 復号方式の比較は**セルマスク有りが seed 1・2、無しが seed 1 のみ**。
  値と点灯数の線形当てはめの残差は調べていない(`REPORT.md` §6.7)
