# 更新対象の選択・ノイズ・マージン(研究メモ)

2026-09-25 の一連の実験の記録。結果として、crow の学習規則を次のように変えた(コミット d3b95c0)。

- 直すニューロンの選び方: 64 個ごとに |z| で並べ替えて上位 k = 64/GroupSize 個を直す方式 → **固定しきい値+マージン**
  - 出力が目標と食い違い、かつ |z| ≤ `MaxUpdateAbsZ` なら、目標の向きへ直す
  - 出力が正解でも |z| < `MarginAbsZ` なら、目標(=今の符号)の向きへ押す(マージン)
- 学習時の z へのノイズ(`MaxAbsNoise`)を**廃止**。順伝播は決定的になった
- 既定の倍率(√fanIn に対する倍率): Dense は `MaxUpdateAbsZ` 1/4・`MarginAbsZ` 1/4、ProductDense は 1/2・1/8

共通条件: 二値化 MNIST / Fashion-MNIST、784→512→1024(通常の層)または同じ幅の ProductDense(2枝)2層、
ETF プロトタイプ、ミニバッチ 1024、`LRHalfPow` 3、`LogitMargin` 0.45。
特記がなければ3シード・30エポックで、**最後の5エポックの平均テスト精度**(%)。
検証データは分けず、テスト精度で比べている(どの方式も同じ条件なので比較には使えるが、絶対値はやや楽観的)。
実験プログラムはスクラッチ上の一時的なもので、リポジトリには残していない。

## 1. 並べ替えをしきい値に置き換えられるか

発端は「並べ替えは可読性もアルゴリズムも重い。もっと単純に選べないか」という問い。
次の2つを試した(MNIST、10エポックまでの最良、3シード)。

- **適応しきい値**: 層ごとの τ を持ち、直した数が旧方式の数に近づくようバッチごとに τ を乗算的に調整する
- **固定しきい値**: τ = √fanIn × 係数

| 選び方 | 直す数(旧方式=1) | 通常の層(ノイズ 1/2) | ProductDense(ノイズ 0) |
|---|---:|---:|---:|
| 並べ替え GroupSize=4(旧既定) | 1 | 90.12 | 94.04 |
| 適応しきい値 | 1 | 90.74 | 93.95 |
| 並べ替え GroupSize=8 | 0.5 | 91.41 | 94.28 |
| 適応しきい値(目標を半分) | 0.5 | 91.60 | 93.77 |
| 固定 τ=√fanIn/4 | 0.2〜0.4 | 91.66 | 93.46 |
| 固定 τ=√fanIn/2 | 0.4〜0.8 | 91.58 | 94.31 |
| 固定 τ=√fanIn | 0.8〜1.1 | 90.70 | 94.02 |

- 精度差の大半は「しきい値かどうか」ではなく「**直す数**」で説明できる。直す数を揃えると、しきい値そのものの効果は小さい
- 適応しきい値は状態・原子的カウンタ・目標の定義(結局 GroupSize が要る)が必要で、単純にならない。採用せず
- 速度差はほとんどない(並べ替える要素は1ワード高々64個)

### 1-1. GroupSize の見直し(30エポック)

| GroupSize | 通常の層 MNIST | ProductDense MNIST |
|---:|---:|---:|
| 4(旧既定) | 90.81 | 94.84 |
| 8 | 91.79 | **95.13** |
| 16 | **92.29** | 94.92 |
| 32 | 92.29 | — |
| 64 | 92.03 | — |

旧既定の 4 は直しすぎだった。最適値は層の種類で異なる(通常の層 16、ProductDense 8)。
ProductDense の最適値が小さい(直す数が多い)のは、1つの食い違いを枝1本でしか直さず1回の修正が弱いためと考えられる。

### 1-2. 固定しきい値の30エポック確認

| 選び方 | 通常の層 MNIST | ProductDense MNIST | 通常の層 Fashion | ProductDense Fashion |
|---|---:|---:|---:|---:|
| 並べ替え GroupSize=4(旧既定) | 90.81 | 94.84 | 83.08 | 84.17 |
| 並べ替え 最良の GroupSize | 92.29(16) | 95.13(8) | 83.81(16) | 84.49(8) |
| 固定 τ=√fanIn/4 | **92.33** | (10エポックで 93.46) | 83.78 | — |
| 固定 τ=√fanIn/2 | 92.06 | **95.25** | 83.71 | **84.71** |

固定しきい値は最良の並べ替えと同等以上で、並べ替えも GroupSize も不要になる。
この時点で crow を固定しきい値に変更した(通常の層 1/4、ProductDense 1/2、ノイズは 1/2 のまま)。

## 2. ノイズは何をしていたのか

固定しきい値の crow で、ノイズ 1/2 と 0 を比べると、0 の方がわずかに良く速かった。

| | ノイズ 1/2 | ノイズ 0 |
|---|---:|---:|
| MNIST | 92.26 | 92.39 |
| Fashion-MNIST | 83.83 | 84.08 |
| MNIST 1エポック目 | 85.72 | 87.77 |
| 学習時間(1エポック) | 0.55 秒 | 0.43 秒 |

### 2-1. 「並べ替えをやめたからノイズが効かなくなった」仮説は外れ

| 選び方 | MNIST ノイズ 1/2 | MNIST ノイズ 0 | Fashion ノイズ 1/2 | Fashion ノイズ 0 |
|---|---:|---:|---:|---:|
| 並べ替え GroupSize=4 | **90.81** | 90.20 | **83.08** | 82.68 |
| 並べ替え GroupSize=16 | 92.29 | **92.60** | 83.81 | **84.17** |

ノイズが効くのは**直す数が多すぎるとき(GroupSize=4)だけ**。並べ替えのままでも直す数が適正ならノイズは逆効果。

### 2-2. 仕組みの切り分け(MNIST、並べ替え GroupSize=4)

| 条件 | 精度 | 直した中の「ノイズが無ければ正解」の割合 | 本当の食い違いを直した割合(30エポック目) |
|---|---:|---:|---:|
| ノイズ 1/2(旧既定) | 90.75 | 34% | 55% |
| ノイズ 0 | 90.35 | 0% | 76% |
| A: ノイズ 0、GroupSize=6(本当に直す数をノイズありと揃える) | 91.40 | 0% | 51% |
| **B: ノイズ 0 + 決定的マージン 12** | **93.13** | 44〜49% | 46% |
| **B: ノイズ 0 + 決定的マージン 24**(ノイズの半幅と同じ) | **93.74** | 54〜55% | 38% |
| C: 並べ替えのキーにだけノイズ | 89.74 | 0% | 76% |
| D: 出力はノイズ無し、食い違いの判定と並べ替えにだけノイズ | 91.22 | 33〜34% | 52% |

- **仮説1(ノイズで本当の修正が減り、直しすぎが和らぐ)**: 一部だけ当たり(A で +0.65pt)
- **仮説2(マージン)**: 本命。ノイズは「|z| の小さい正解ニューロンを、確率的に正しい向きへ押す」ことで
  マージン付きパーセプトロン(ヒンジ損失)を近似していた。決定的なマージンにするとノイズを大きく上回る
- **仮説3(直すニューロンの偏りを防ぐ)**: 外れ(C はノイズ無しより悪い)
- **D**: 出力そのものを揺らすこと(次の層・更新判定へ揺れた出力を渡すこと)は害だった

ノイズ側も同じ30エポックで、5エポックごとの平均は 90.40 → 90.52 → 90.69 → 90.75 とほぼ頭打ち
(マージン 24 は 93.01 → 93.37 → 93.58 → 93.74 でまだ伸びている)。エポック不足で負けたのではない。

[REPORT.md](REPORT.md) §1 のノイズ注入の意図「更新の確率化・安定化」は、実際には「確率的なマージン」として働いていたと解釈し直せる。
§5 の CP+R 強化ステップ(`h ← h + 2·sign(h)`、隠れ重みの絶対値を強める)は z に作用するものではなく、今回のマージンとは別物。
BEP 論文の robustness r は最終層のロジットへのマージン(crow の `LogitMargin`)で、隠れ層のニューロン単位のマージンは論文にも無い。
論文は隠れ層で「食い違ったニューロンのうち最も直しやすいもの」だけを更新する。

### 2-3. ノイズの減衰(参考)

固定しきい値 1/4・マージン無しで、ノイズ倍率を学習とともに線形に 0 へ下げた(MNIST)。

| スケジュール | 精度 |
|---|---:|
| 1/2 のまま | 92.26 |
| 0 | 92.39 |
| 1/2 → 0(10エポックで) | 92.55 |
| 1/2 → 0(30エポックで) | 92.66 |
| 1 → 0(30エポックで) | 92.78 |

減衰は +0.2〜0.4pt 効くが、決定的マージン(93.6 前後)には約 0.9pt 届かず、調整項目も増える。採用せず。

## 3. しきい値+マージン(ノイズ 0)

「食い違いで |z| ≤ τ」または「正解で |z| < m」を直す。τ・m は √fanIn に対する倍率。

### 3-1. 通常の層

| τ | m | MNIST | Fashion-MNIST |
|---:|---:|---:|---:|
| 1/4 | 0(マージン無し) | 92.39 | 84.07 |
| **1/4** | **1/4** | 93.57 | **84.83** |
| 1/2 | 1/2 | **93.66** | 84.80 |
| 1/8 | 1/4 | 93.60 | 83.98 |
| 1/4 | 1/2 | 93.52 | — |
| 1/8 | 1/2 | 92.77 | — |
| 1/4 | 3/4 | 89.52 | — |
| 1/4 | 1 | 約23%(1シード2エポックで崩壊) | — |

- マージンで +1.2pt(MNIST)・+0.8pt(Fashion)。τ・m の広い範囲で 93.5〜93.7 に収まる
- **m を大きくしすぎると崩れる**(正解側を直しすぎる)。上限のある並べ替え版と違い、しきい値版は m ≤ 1/2 が安全
- τ = 1/8 は Fashion でマージン無しより悪い

### 3-2. ProductDense(τ = 1/2)

| m | MNIST | Fashion-MNIST |
|---:|---:|---:|
| 0 | 95.20 | 84.57 |
| **1/8** | **95.32** | 84.78 |
| 1/4 | 94.90 | **84.89** |
| 1/2 | 93.60 | 84.66 |
| (τ = 1/4)1/4 | 94.15 | 84.70 |

マージンは「出力は正解だが枝の |z| の最小値が m 未満」のとき、|z| が最小の枝を今の符号の向きへ押す形で実装した。
効果は通常の層より小さい(+0.1〜0.2pt)。m = 1/4 は MNIST で逆効果なので 1/8 を採用。

### 3-3. crow 本体での確認(MNIST、2シード)

| | 最後の5エポックの平均 |
|---|---:|
| 通常の層 | 93.68 / 93.63 |
| ProductDense | 95.39 / 95.47 |

## 4. 回帰での確認

温度計プロトタイプ 101 レベル、点灯数で復号。20エポック、3シードのテスト MAE(小さいほど良い)。
合成タスクは 256 ビット入力で、隠れた 64 ビット群 A・B の点灯率 a・b から値を作る
(線形 = 128 ビットの点灯率、積 = a·b、波 = (sin 2πa + 1)/2)。

| タスク | 通常 ノイズ 1/2 | 通常 ノイズ 0 | 通常 ノイズ 0+マージン 1/4 | 積の層 マージン無し | 積の層 マージン 1/8 |
|---|---:|---:|---:|---:|---:|
| 線形 | 0.0107 | **0.0084** | 0.0092 | 0.0235 | **0.0182** |
| 積 | 0.0356 | 0.0356 | **0.0353** | 0.0509 | **0.0450** |
| 波 | 0.0952 | 0.0967 | **0.0941** | 0.0706 | **0.0433** |
| MNIST の数字(0〜9) | **0.757** | 0.855 | 0.925 | 0.945 | **0.921** |

ProductDense はマージンで全タスク改善。通常の層は合成タスクでは同等以上だが、**MNIST の数字を値として回帰させると悪化**した。

### 4-1. MNIST の数字の回帰の診断(通常の層、40エポック)

| 条件 | テスト MAE(10 / 40エポック) | 学習 MAE(10 / 40) | 数字が当たる割合(10 / 40) |
|---|---:|---:|---:|
| ノイズ 1/2 | **0.734** / **0.769** | 0.733 / 0.752 | 65% / 52% |
| ノイズ 1/2→0 減衰 | 0.737 / 0.793 | 0.734 / 0.772 | 61% / 46% |
| ノイズ 0 + マージン 1/8 | 0.803 / 0.781 | 0.801 / 0.757 | 53% / 50% |
| ノイズ 0 | 0.904 / 0.840 | 0.896 / 0.820 | 45% / 44% |
| ノイズ 1/2 + マージン 1/4 | 0.909 / 0.891 | 0.894 / 0.871 | 53% / 53% |
| ノイズ 0 + マージン 1/4 | 0.946 / 0.917 | 0.936 / 0.896 | 48% / 46% |

(「数字が当たる」は予測値を四捨五入して正解と一致した割合)

- **過学習ではない**(学習 MAE ≒ テスト MAE)。どの条件も学習データにすら当てはまらず、20エポック以降は学習 MAE 自体が悪化する
- 数字の見た目と値の大小に関係が無い課題を温度計の点灯数で表させるため目標の一貫性が低く、
  隣接レベルが約10ビットしか離れないので更新判定がほぼ常に真になり、学習が落ち着かない
- この不安定な状況では、ノイズのランダムさが「当てはめを進める」方向に働くと考えられる
- 分類すべきものを無理に回帰させた人工的な課題で、全条件が失敗している中での差と判断し、ノイズ廃止を優先した

## 5. MLP-Mixer 型(否定的な結果)

入力をパッチ(7×7 のパッチ16個 = 16×49 の行列)に並べ替え、転置するだけの層を挟んで
token-mixing(パッチ間)と channel-mixing(パッチ内、`Dense` が全行に同じ重みを使う)を交互に行う構成を試した。
crow の記録領域が「全層の入力の行数が同じ」前提なので、実験用のコピーで層ごとの行数を渡すよう直して試した。

| 構成(MNIST、1シード) | 精度 | 1エポック |
|---|---:|---:|
| 通常の2層(1×784) | 90.0%(2エポック) | 0.6 秒 |
| 転置を2回挟むだけ(通常の2層) | 90.6%(2エポック) | 0.6 秒 |
| パッチごとの2層(token-mixing 無し) | 約55%(4エポック) | 0.6 秒 |
| token-mixing を隠れ層に(Mixer の1ブロック) | 12〜34%(5〜10エポック) | 1.1〜7.5 秒 |
| token-mixing を出力層に | 63%(10エポック) | 12 秒 |
| パッチ構造のまま3層 | 40%(4エポック) | 1.0 秒 |

- 転置そのものは正しく動く(通常の2層と同じ精度)
- パッチ構造で隠れ層を持つと BEP ではほぼ学習できない。各パッチだけではクラスを決められず、隠れ層へ届く目標が矛盾するためと考えられる
- 行数が増えるため学習が10〜20倍遅く、BEP の利点が消える。途中で打ち切り、採用しない

## 6. 留保

- MNIST / Fashion-MNIST の2データセット、3シード、テスト精度での比較。検証データでの選択はしていない
- 既定の倍率(1/4・1/4、1/2・1/8)は粗いグリッドから選んだもので、細かくは詰めていない
- マージンと他の要素(`LRHalfPow`、`LogitMargin`、層の幅)の相互作用は調べていない
