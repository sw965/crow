# 調査・実験報告: 純粋な二値NNで TM 並みの精度を出す

- 日付: 2026-08-14
- 依頼: 「第1層から出力層まで純粋なニューラルネットワーク構造は崩さず、3値は導入せず、
  BEPの高速性の核は崩さず、実用的な精度が出て、万能近似定理を満たすモデルを模索する」
- 前提となる経緯: 同じフォルダ階層の `../tsetlinlab/REPORT.md` で Tsetlin Machine (TM) が
  MNIST 97.24 ± 0.12% / Fashion-MNIST 87.44 ± 0.11% を出し、crow の BEP 実装
  (MNIST 92.13 ± 0.48% / Fashion 83.78 ± 0.03%、`../REPORT.md`)を大きく上回った。
  本報告は「TMではなく、NNの側で同等以上を出す」ための探索である。
- 実験環境: Windows 11 / Go 1.26.5 / 12論理コアCPU
- 実験コード: `model/`(最終モデル)、`ablation/`(特徴と読み出しの対照実験)、
  `bepreadout/`(BEPの読み出し差し替え診断)。生ログ: `LOGS.md`
- crow / omw のライブラリコードは一切変更していない(公開APIのみ使用)

## 1. 結論

**局所受容野を持つ二値ニューロン層 + 整数重みの出力層**、第1層は**競合学習**、
出力層は**マージン付き平均化パーセプトロン**で学習する構成が、全条件を満たした。

| データセット | 本手法 | TM | crow BEP | BEP論文報告 |
|---|---:|---:|---:|---:|
| MNIST | **97.97 ± 0.07%** (3シード) | 97.24 ± 0.12 | 92.13 ± 0.48 | — |
| Fashion-MNIST | **87.96%** (1シード) | 87.44 ± 0.11 | 83.78 ± 0.03 | 85〜87% |

| 制約 | 判定 | 根拠 |
|---|---|---|
| 純粋なNN構造、全層が学習される | ✅ | §3.1。第1層=局所受容野の二値ニューロン(畳み込み層と同型)、出力層=線形層。両方とも学習する |
| 3値重みを導入しない | ✅ | §3.1。可視重みは ±1 のみ。「見ない画素」は重み0ではなく**結線が無い**(受容野の外)ため、重みの値域は2値のまま |
| BEPの高速性の核を崩さない | ✅ | §3.2。順伝播は XOR + popcount、学習は整数カウンタの ±1 と整数比較のみ。浮動小数点ゼロ |
| 実用的な精度 | ✅ | 上表 |
| 万能近似 | ✅(条件付き) | §5。ただし全結合層を1枚置ける族にしておく必要がある |

そして探索の過程で、当初の見立てを覆す結果が2つ出た。これが本報告の主内容である。

- **BEPの弱点は表現力ではなく学習則の側にある**(§2)
- **誤差駆動のHebbian則は第1層の特徴を破壊する。競合学習なら改善する**(§4)

## 2. 何がBEPとTMの差を作っているのか(切り分け実験)

隠れ層を固定(学習しない)にし、読み出しを揃えて特徴の質だけを比較した(`ablation/`)。
読み出しは全て整数重みのマージン付きパーセプトロン。

### 2.1 特徴の種類と幅

MNIST、整数線形読み出し(平均化なし)。

| バックボーン | 幅1024 | 幅8192 |
|---|---:|---:|
| BEP学習済み(単層。参考値) | 91.19% | 93.97% |
| ランダム dense(しきい値0。BEPのDense層と同じ形) | 92.74% | 95.93% |
| ランダム dense + ランダム整数バイアス | 91.11% | 95.51% |
| ランダム AND(k=8。TMの節と同型) | 94.77% | 97.31% |
| ランダム 局所受容野(9x9 + 整数バイアス) | — | 97.39% |

読み取れること。

1. **BEPの学習済み特徴は、同じ幅のランダム特徴より弱い**(8192で 93.97 vs 95.93)。
   BEPの学習は、少なくともこの設定では特徴を改善していない
2. **バイアスを無作為に散らすだけでは効かない**(95.93 → 95.51 と微減)。
   当初「BEPにバイアスが無いのが原因」と見立てたが、この形では**外れ**だった。
   ただし**これは「バイアスが不要」という意味ではない。** 測ったのは
   「全結合ニューロンに、一様乱数で選んだバイアスを与える」という1条件だけである。
   実際、しきい値(=バイアス)の**値**は精度を大きく左右する。
   局所受容野9x9では一致率 85% → 90% で 97.39 → 96.49、ランダム初期化では
   55% → 65% で 97.02 → 90.29 と動く(LOGS.md §1.7 / §3.3)。
   §3 の提案モデルも、適切な値に設定した固定バイアスに依存している。
   **効かなかったのは無作為な散らし方であって、適切な値のバイアスはむしろ必須。**
   学習可能なバイアスの効果は本実験では分離して測っていない
3. **効くのは「無関係な入力を見ない」こと**。AND型(k=8)も局所受容野(9x9)も、
   一部の入力しか見ない部分パターン検出器で、どちらも 97.3〜97.4% に届く。
   全784入力が必ず投票する dense 型は 95.9% で頭打ち

TMの節は各リテラルを包含/除外でき、除外は実質 don't care(実効的に3値)。
BEPの可視重みは ±1 のみで「無視」を表現できない。ここが差の本体である。
ただし **don't care を得る手段は3値化だけではない**。受容野を局所化すれば、
重みの値域を2値に保ったまま同じ効果が得られる(=畳み込み)。これが本手法の出発点。

### 2.2 AND型のパラメータ(参考)

| k(リテラル数) | 4 | 6 | 8 | 12 | 16 | 24 |
|---|---:|---:|---:|---:|---:|---:|
| MNIST(H=8192) | 96.61 | 97.04 | 97.31 | 97.16 | 96.93 | 95.15 |
| 活性率 | 0.417 | 0.275 | 0.186 | 0.086 | 0.044 | 0.012 |

幅の効果(k=8): 2048 → 95.89、4096 → 96.91、8192 → 97.31、16384 → 97.57、32768 → 97.45。
16384 で頭打ちになる。

### 2.3 読み出しの寄与(BEPの読み出しだけを差し替える)

`bepreadout/` で、BEPを通常どおり学習させた後、その活性に対して整数線形読み出しを
学習させ、固定プロトタイプ読み出しと比較した(いずれも15エポック)。

| BEP構成 | プロトタイプ読み出し | 整数線形読み出し | 差 |
|---|---:|---:|---:|
| 784→512→1024 | 90.01% | 90.23% | +0.22 |
| 784→1024(単層) | 89.43% | 91.19% | +1.76 |
| 784→8192(単層) | 89.24% | 93.97% | +4.73 |

**幅を広げるほど、固定プロトタイプ読み出しが取りこぼす情報が増える。**
ただし読み出しを直しても 93.97% までで、特徴の質(§2.1)の差は埋まらない。
BEP論文が分類器を固定する設計は、幅が小さいうちは実害が小さいが、
幅で精度を稼ごうとすると足枷になる。

### 2.4 平均化パーセプトロン

読み出しの学習を平均化パーセプトロン(Daumé のトリック。`w - u/count` の整数除算)に
すると、MNIST +0.19pt、Fashion **+2.2pt**(85.87 → 88.09)と大きく効いた。
整数のみで実装できるため、制約に抵触しない。

### 2.5 効かなかったもの

- **全結合ニューロンへの、無作為な値の整数バイアスの追加**(§2.1)。
  バイアスそのものが無効という意味ではない(§2.1 の読み取り2を参照)
- **整数スコアによる特徴選抜**: 候補を4〜16倍作り、クラス別発火数の偏り
  `max_c(n_c * C) - n` で上位を残す方式。MNIST H=8192 で over=1: 97.50、
  over=4: 97.50、over=16: 96.91。**改善せず、強くすると悪化**。
  単変量選択が冗長(相関の強い)特徴ばかり選ぶ典型的な失敗と考えられる
- **読み出しのマージンの調整**: Fashion で 5 / 25 / 50 / 100 を試したが大差なし

## 3. 提案モデル

### 3.1 構造

```text
入力: 28x28 の1bit画像

第1層(学習する): 局所受容野を持つ二値ニューロン H 個
  ニューロン i は、画像上の p x p パッチ(位置 (r0_i, c0_i))だけに結線される
  パッチ内の各画素に ±1 の二値重み W_i、ニューロンごとに整数バイアス b_i
  z_i = (一致数 - 不一致数) + b_i = area - 2*不一致数 + b_i
  a_i = [z_i >= 0]

出力層(学習する): クラスごとの整数重み
  logit_c = bias_c + Σ_{i: a_i = 1} Wout[c][i]
  予測 = argmax_c logit_c
```

- **3値ではない**: 重みの値域は {+1, -1} のみ。受容野の外の画素は「重み0」ではなく
  結線されていない。これは畳み込み層の受容野と同じ、純粋なNNの構造である
- 第1層は BEP と同じく、整数の隠れ重み H(int8)を持ち、可視重みは W = sign(H)。
  H はシナプス慣性として働き、符号が変わったときだけ W のビットが反転する
- 受容野の位置は、競合学習の単位を作るために全位置へ均等に割り当てる
  (同じ位置に `perPos = H / 位置数` 個のニューロンを置き、その中で競合させる)

### 3.2 演算(全て整数・ビット演算)

| 処理 | 演算 |
|---|---|
| 第1層の順伝播 | `(x XOR W) AND mask` の popcount(触るのは受容野がまたぐ数ワードのみ)+ 整数加算 |
| 活性 | 整数の符号判定 |
| 出力層 | 発火した特徴の整数重みの加算(乗算なし) |
| 予測 | 整数比較の argmax |
| 第1層の学習 | 一致数の整数比較(勝者選出)+ 整数カウンタ H の ±1 + 符号反転時のビット反転 |
| 出力層の学習 | 整数の ±1 更新、マージンの整数比較、平均化は `w - u/count` の整数除算 |
| 乱数 | xorshift64*(整数のみ) |

学習・推論の経路に浮動小数点は現れない(精度の表示のみ float)。

### 3.3 学習手順

1. **第1層: 競合学習**(教師なし、数エポック)
   サンプルごとに、各受容野位置のニューロン群の中から、そのパッチに最も一致する
   1個(勝者)を選び、勝者だけを入力へ近づける(H に ±1、符号が変われば W を反転)。
2. **出力層: マージン付き平均化パーセプトロン**(教師あり)
   正解クラスのロジットが最良の誤クラスより margin 以上大きくなければ、
   発火している特徴について正解クラスの重みを +1、誤クラスの重みを -1。

### 3.4 最良設定と結果

```sh
# MNIST 97.97 ± 0.07% (シード1/2/3 で 97.95 / 98.06 / 97.90)
go run ./model -hidden 16384 -patch 9 -randinit -matchpct 70 -vq 3 -freeze1 -epochs 20

# Fashion-MNIST 87.96%
go run ./model -dataset fashion -hidden 16384 -patch 9 -randinit -matchpct 55 -vq 3 -freeze1 -epochs 20
```

`-freeze1` は「§4 の誤差駆動更新を止める」フラグで、`-vq` による競合学習はその前段で
実行される。したがってこの設定でも**第1層は学習されている**。

`-matchpct` は初期しきい値(発火に要する一致率)。競合学習後のテンプレートは実データの
クラスタ中心になるため、MNIST では 70%、Fashion では 55% が良かった。

## 4. 第1層の学習則についての知見(本報告の主要な発見)

**誤差駆動の Hebbian 則(BEPと同じ構造)は、第1層の特徴を一貫して悪化させた。**

MNIST、H=4096、8エポック、データ由来の初期化。凍結(学習しない)が 96.98%。

| 第1層の更新強度 | 精度 |
|---|---:|
| 更新確率 1/8、重要度しきい値 2(強い) | 92.34% |
| 1/64、4 | 94.87% |
| 1/256、4 | 96.20% |
| 1/1024、4 | 96.89% |
| 1/4096、8(ほぼ更新しない) | 97.00% |

**更新を弱めるほど凍結に近づいて良くなる**という単調な関係だった。
BEP Eq.9 のマスク(グループ内で1個だけ更新)や、出力層だけを先に学習するウォームアップを
足しても改善しなかった(94.38〜96.13%)。

初期化のせいではない。ランダム初期化でも同じ結果になる(10エポック)。

| 初期化 | 凍結 | 誤差駆動で学習 |
|---|---:|---:|
| ランダム(matchpct=55) | 97.02% | 89.66% |
| ランダム(matchpct=60) | 96.53% | 86.68% |
| ランダム(matchpct=65) | 90.29% | 89.02% |

**原因の解釈**: 誤差駆動 Hebbian は「間違いを起こしたサンプル」へニューロンを引き寄せる。
多数のニューロンが同じ方向へ流れるため、特徴が平均化されて多様性が潰れる。
グループ内1個更新の制約を入れても、エポックを通せば各ニューロンが多数の異なるサンプルへ
順に引き寄せられるため、崩壊は止まらない。

**競合学習(勝者のみ更新)なら改善する。** 勝者=既に最もよく合っているニューロンだけを
更新するので、各ニューロンが自分の得意な部分パターンへ特化していき、多様性が保たれる。

| 第1層の扱い(MNIST H=4096、ランダム初期化、出力10エポック) | 精度 |
|---|---:|
| 競合学習なし(凍結) | 96.89% |
| 競合学習 1エポック | 97.23% |
| 競合学習 3エポック | 97.24% |

これは §2.1 の「BEPの学習済み特徴はランダム特徴より弱い」という測定とも整合する。
**BEPの弱点は表現力ではなく学習則の側にある**、というのが本探索の結論である。

なお本手法の競合学習は**教師なし**である。全層が学習される条件は満たすが、
第1層は誤差信号を受け取っていない。end-to-end の誤差駆動で第1層を改善する方法は
**今回見つからなかった**。これは未解決の課題として残る(§7)。

## 5. 万能近似について

`../UNIVERSAL_APPROXIMATION.md` と同じ「モデル族」(ε ごとに入力精度・出力精度・幅を
増やせる)の意味で成立する。ただし条件がある。

1. **整数バイアスがあるので、同文書 §4.2 の検出ニューロン `sign(pᵀx − (d−1))` を
   そのまま構成できる。** これは同文書 §5.1 が「全層に整数バイアスを持たせよ」と
   要求しているものそのもので、本手法は最初からそれを満たしている
2. **ただし局所受容野だけでは足りない。** 受容野が p x p に限られるニューロンは、
   全入力にまたがるパターンを1個で検出できない。したがって万能近似性を主張するには、
   **最後に全結合層(受容野=全入力)を1枚置ける族**にしておく必要がある。
   本実験のモデルは第1層が局所受容野のみなので、この点は**設計上の注意であって
   実験で確かめた事実ではない**
3. 可変精度の入出力は同文書 §4.1 / §4.3 / §5.3 / §5.4 の構成がそのまま使える
4. 同文書 §4.4 の「固定ビット幅では万能近似にならない」も同様に当てはまる。
   幅・受容野・整数型幅を ε に応じて増やせる族としてのみ主張できる

表現能力と学習可能性の分離(同文書 §7)も同じく必要である。§4 が示したとおり、
本手法は「表現できるが、その状態へ学習で到達できるとは限らない」典型例になっている。

### 5.1 固定分類器 P にバイアスが要るかは、構成の取り方で変わる

BEP論文の固定分類器 `P`(クラスごとのプロトタイプ行)について、
「P 自体にも整数バイアスが必要か」は**構成に依存する**。取り違えやすいので記録する。

**必要になる構成**: 入力パターン検出ニューロンを `P` へ直接つなぐ場合。
検出ニューロンは `x = p` のときだけ +1、他は −1 なので、

```text
logit_c = Σ_p P[c][p]·a_p(x) = 2·P[c][x] − S_c      S_c = Σ_p P[c][p]
```

`S_c = 2·n_c − N`(n_c = クラスcのパターン数)はクラスごとに異なるため、
パターン数が2個以上多いクラスがあると argmax が壊れる。
例: 全5パターンのうち4個がクラスA、1個がクラスBだと、
`logit_A = 2−3 = −1`、`logit_B = −2+3 = +1` となり、**全入力がBに分類される**。
この構成では出力バイアス `b_c = S_c` が要る(同文書 §4.2 の `S_k`)。

**不要にできる構成**: 検出層と `P` の間に、正解クラスのプロトタイプ `ρ^c` を
そのまま出力する Dense 層(整数バイアスあり)を挟む場合。
最終活性が `ρ^c` に一致すれば `⟨ρ^c, ρ^c⟩` が最大になるので、
プロトタイプが互いに異なる限り `P` 自体にバイアスは要らない。
BEPの希望活性 `a*_L = ρ^{c^μ}` はまさにこの形なので、こちらの方がBEPの設計に沿う。

したがって正確な言い方は「**必要な二値しきい値層に整数バイアスを付ければよい。
固定分類器 `P` 自体へのバイアスは必須ではない**」であり、
`UNIVERSAL_APPROXIMATION.md` §5.1 の「各Dense層へ整数バイアス」で足りる。
ただし回帰用の出力ビットを生成する層も Dense 層として数える必要がある。

## 6. BEPへ反映するとしたら

crow の `binary` パッケージを変更する場合の候補(本報告では**実施していない**)。

1. **受容野の局所化**: `Dense` に加えて、局所受容野を持つ層を追加する。
   重みは ±1 のままでよく、3値化は不要。効果が最も大きい(§2.1)
2. **ニューロンごとの整数バイアス**: `UNIVERSAL_APPROXIMATION.md` §5.1 の段階1そのもの。
   単独では効かないが(§2.1)、局所受容野と組み合わせるとしきい値の調整に必要になる
3. **出力層の学習**: 固定プロトタイプを整数重みの学習可能な読み出しに替える。
   幅を広げるなら必須(§2.3)。可視重みを二値に保ちたい場合は、
   クラスごとに m 本の二値行を持たせて票を合計すれば、実効的に整数重み相当になる
   (`UNIVERSAL_APPROXIMATION.md` §5.1 の重み複製と同じ考え方)
4. **読み出しの平均化**: 整数のみで実装でき、Fashion で +2.2pt(§2.4)
5. **第1層の学習則の見直し**: 誤差駆動 Hebbian から競合学習へ(§4)

## 7. 制約・注意(この報告の限界)

- MNIST は3シード、**Fashion は1シードのみ**
- 各実行の**最良エポックのテスト精度**を報告している。TM(`../tsetlinlab/`)とは
  同条件なので比較は公平だが、絶対値はやや楽観的。
  `../REPORT.md` の BEP 値は検証分離で測られているため、BEPにはやや厳しい比較になる
- **第1層の競合学習は教師なし**。end-to-end の誤差駆動学習で第1層を改善する方法は
  見つかっていない(§4)
- 万能近似性は「全結合層を1枚置ける族」であることが前提(§5)。
  本実験のモデル単体で確かめたわけではない
- ハイパーパラメータの探索は粗い(patch、matchpct、幅を数点ずつ)
- CIFAR-10 級の複雑なデータセットでは未検証。
  §4 の知見(誤差駆動が効かない)は、階層的な表現学習が必要な問題では
  そのまま制約になる可能性がある
